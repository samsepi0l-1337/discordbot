# `/rr` 상세 가이드 (Reaction Roles)

`/rr` 명령어는 특정 메시지에 리액션을 추가하거나 제거할 때 유저의 역할을 자동으로 관리하는 기능을 제공합니다.

---

## 1. 핵심 메커니즘: Active Message (활성 메시지)

규칙을 추가하기 전에, 어떤 메시지에 규칙을 적용할지 봇에게 알려줘야 합니다.

1. **`/rr channel`**: 메시지가 있는 채널을 선택합니다.
2. **활성 메시지 설정 (세 가지 방법)**:
    - **방법 A (컨텍스트 메뉴)**: 대상 메시지를 **우클릭(또는 길게 누르기) > 앱(Apps) > RR: 활성 메시지로 설정**을 클릭합니다.
    - **방법 B (답글)**: 대상 메시지에 **답글(Reply)**을 유지한 채로 `/rr message` 명령어를 입력합니다. (ID 입력 생략 가능)
    - **방법 C (ID 직접 입력)**: `/rr message message_id:<메시지ID>`를 직접 입력합니다.

---

## 2. 룰 타입별 동작 로직 (`ReactionRoleService`)

모든 리액션 역할 추가(`add`) 및 삭제(`delete`) 명령어는 **대상 메시지에 답글(Reply)을 달고 실행**하면 자동으로 해당 메시지를 대상으로 인식합니다.
명시적으로 ID를 입력하지 않아도 되므로 훨씬 편리하게 관리할 수 있습니다.

각 규칙은 `rr_rules` 테이블에 저장되며, 리액션 발생 시 다음과 같이 처리됩니다.

### `normal` (일반)

- **추가 시**: 역할 부여 + 설정 시 DM 알림
- **제거 시**: 역할 제거 + 설정 시 DM 알림
- **용도**: 공지 확인, 일반적인 역할 선택

### `once` (단발성)

- **추가 시**: 역할 부여 + **봇이 해당 리액션을 즉시 삭제**
- **제거 시**: 동작 없음 (이미 삭제됨)
- **용도**: 규칙 동의 후 다시 취소할 수 없게 할 때 사용. (동일 메시지에서 다른 타입과 혼용 불가)

### `remove` (제거기)

- **추가 시**: 유저가 가진 해당 역할을 **박탈**
- **용도**: "역할 초기화" 버튼 등에 활용

### `toggle` (토글/그룹)

- **매개변수**: `group` (그룹 이름)
- **추가 시**:
    1. 동일한 그룹(`toggle_group`)에 속한 다른 규칙들을 검색합니다.
    2. 유저가 가진 다른 그룹 내 역할을 모두 제거합니다.
    3. 현재 선택한 이모지에 해당하는 역할을 부여합니다.
- **용도**: 색상 역할, 팀 선택 등 하나만 선택해야 하는 경우

---

## 3. 기타 역할 부여 로직

### `/rr autorole` (자동 역할)

- **대상**: `user` (일반 유저), `bot` (봇)
- **로직**: `guildMemberAdd` 이벤트 시 즉시 실행됩니다. (딜레이 없음)
- **결과**: 입장하자마자 특정 역할을 부여받습니다.

### `/rr timed` (시간 지연 역할)

- **매개변수**: `time` (예: `10s`, `10m`, `1h`, `1d`)
- **로직**:
    1. 입력된 시간을 파싱하여 ms 단위로 변환합니다.
    2. `guildMemberAdd` 이벤트 발생 시 `setTimeout`을 통해 예약 실행됩니다.
- **결과**: 입장 후 10초/10분 뒤, 혹은 하루 뒤에 자동으로 역할이 부여됩니다.

### `/rr voice` (음성 채널 역할)

- **로직**:
    1. `voiceStateUpdate` 이벤트를 감시합니다.
    2. 채널 접속(`join`) 시 해당 채널에 매핑된 역할을 부여합니다.
    3. 채널 퇴장(`leave`) 시 해당 역할을 제거합니다.
- **결과**: 음성 채팅 중인 유저를 쉽게 식별할 수 있습니다.

---

## 4. 관리 및 정리

- **`/rr list`**: 등록된 모든 리액션 규칙을 메시지별로 그룹화하여 보여줍니다.
- **`/rr delete check`**: 서버에서 삭제된 역할이 규칙에 남아있거나, 메시지가 삭제된 경우 이를 찾아 데이터베이스를 정리합니다.
- **`/rr dm`**: `on` 설정 시 유저가 리액션을 할 때마다 "역할이 부여/제거되었습니다"라는 메시지를 봇이 DM으로 전송합니다.
